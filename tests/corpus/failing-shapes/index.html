Corpus of failing shapes

This tree exists to be audited, not to be read. Each page carries defects that a real site carries by accident, so that the verdict census can show which checks are able to report a failure at all and which have never been seen doing it.

The pages are invented. The shapes are not: an over-long title, a deferred hero image, a retired schema type, a category page with nothing in it and a sitemap that disagrees with the tree are all ordinary things to find on a site nobody has audited.

What is here

A catalogue page with no products, a page at a URL nobody would type twice, a page too thin to answer anything, and a stylesheet whose web font blocks the first paint. The navigation above repeats one anchor phrase four times, which is the shape an anchor-text audit is meant to notice.

Corpus Shapes. Not a real business, and deliberately without an address, a telephone number or opening hours.
